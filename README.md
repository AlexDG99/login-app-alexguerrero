
# Aplicación de inicio de sesión

## Descripción
Este proyecto consiste en un formulario de inicio de sesión desarrollado con HTML, CSS y JavaScript. Permite ingresar un usuario y una contraseña, además de validar que los campos no estén vacíos.

## Tecnologías utilizadas
- HTML5
- CSS3
- JavaScript
- Git y GitHub
- GitHub Actions

## Estrategia de ramas

Para este proyecto se utiliza GitHub Flow, porque es una estrategia sencilla que permite desarrollar funcionalidades en ramas independientes y luego integrarlas mediante Pull Requests.

La rama `main` contiene la versión principal del proyecto. Para implementar el formulario se creó la rama `feature/formulario-login`. Una vez terminados los cambios y realizadas las pruebas, la funcionalidad se integrará a `main` mediante un Pull Request revisado por un compañero.

Esta estrategia facilita la revisión de los cambios, el trabajo colaborativo y la detección de errores antes de integrar las funcionalidades.

## Ejecución
Abre el archivo `index.html` en un navegador web.

## Alcance
El formulario valida que los campos de usuario y contraseña no estén vacíos. No realiza autenticación real contra una base de datos.
